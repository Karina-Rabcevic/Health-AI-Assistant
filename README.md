
# Health AI Assistant

Учебный проект Telegram-бота для оценки риска сердечных заболеваний с использованием машинного обучения и искусственного интеллекта.

## Возможности

- Опрос пользователя и сбор данных
- Проверка введённых данных
- Оценка риска с помощью модели машинного обучения
- Пояснение результатов с использованием языковой модели
- Предоставление информационных рекомендаций

## Технологии

- Python
- aiogram
- Random Forest
- OpenRouter API
- Machine Learning

## Примечание

Проект носит учебный и информационный характер. Результаты не являются медицинским диагнозом и не заменяют консультацию врача.
